1. Before You Start

1.1 What you need

  • A tablet or phone (Android or iOS) per register, connected to Wi-Fi.
  • Your Location ID and Location password (created during onboarding — see the User Manual, Chapter 3).
  • A receipt printer, if you plan to print physical receipts. Mintcom also works with no printer at all — receipts can still be viewed and emailed.
  • A stable router/Wi-Fi network. If you're using a network printer, the tablets and the printer must be on the same network.

1.2 Minimum device requirements

PlatformMinimumRecommended
AndroidAndroid 7.0 (Nougat) or laterA mid-range tablet from the last 3–4 years, e.g. Samsung Galaxy Tab A/S series
iOS / iPadOSA currently-supported iPad model with an up-to-date iOS/iPadOS versioniPad (9th generation or later), iPad Air, or iPad Pro
Tip: Mintcom is a standard app on standard tablets — there is no proprietary or locked hardware requirement. Any device that meets the minimums above will run it smoothly.

2. Tablet & Phone Setup

2.1 Install the app

  1. iPad/iPhone: open the App Store, search "Mintcom POS", install.
  2. Android: open Google Play Store, search "Mintcom POS", install.
  3. Open the app, enter your Location ID and Location password, and tap Connect. The device is now bound to your store — each staff member can sign in with their own username afterward (User Manual, Chapter 7.1).

2.2 Lock the tablet to Mintcom (recommended for shared/counter devices)

These are standard operating-system features (not part of Mintcom) that stop staff or customers from leaving the POS app accidentally.

iPad — Guided Access

  1. Settings › Accessibility › Guided Access › toggle it On.
  2. Set a Guided Access passcode (use a different one from the device passcode).
  3. Open Mintcom POS, then triple-click the side (Top) or Home button.
  4. Tap Start in the top-right corner. The iPad is now locked to Mintcom.
  5. To exit: triple-click the same button and enter the Guided Access passcode.

Android — App Pinning

  1. Settings › Security › Advanced › App Pinning (path varies slightly by manufacturer) › toggle it On.
  2. Open Mintcom POS, then open the Recent Apps (Overview) screen.
  3. Tap the app icon at the top of the Mintcom card and select Pin.
  4. To unpin: press and hold Back and Overview together (or follow your device's unpin gesture).

3. Choosing a Receipt Printer

3.1 How Mintcom connects to printers

Mintcom POS supports two connection types for receipt and kitchen printers:

ConnectionBest forNotes
Network (Wi-Fi/LAN)Fixed counters, multiple tablets sharing one printer, kitchen printersMost stable option. Every tablet on the network can print to it.
BluetoothSingle-tablet setups, mobile carts, food trucks, pop-upsOne printer pairs to one device at a time.
USB printers are not supported. Choose a printer with Network (Ethernet/Wi-Fi) or Bluetooth connectivity — not a USB-only model.

Any standard ESC/POS-compatible thermal receipt printer with one of the two connections above will work. You are not locked into one brand.

3.2 Popular compatible models

These are commonly used, reliable ESC/POS thermal printers — not the only options, just a safe starting point if you're buying new hardware:

  • Epson — TM-T88VI, TM-m30II (both offer Bluetooth and Network versions)
  • Star Micronics — TSP143III (LAN/Bluetooth), mC-Print3

4. Connecting a Network (Wi-Fi/LAN) Printer

Network printers are the most stable choice and let every tablet in the store print to the same printer.

4.1 Wire it up

  1. Plug the printer into power.
  2. Connect an Ethernet cable from your router or network switch to the printer. (Some models also support Wi-Fi directly — follow that printer's own Wi-Fi setup steps if so.)
  3. Turn the printer on and wait for the "Ready" light.

4.2 Find its IP address

  1. Print a network status/self-test sheet — usually by holding the Feed button while powering the printer on, or pressing a small reset button on the back for a few seconds (check your model's manual, as the exact method varies).
  2. Note the IP address shown (e.g. 192.168.1.50).

4.3 Static IP is strongly recommended

Assign the printer a static IP (or a DHCP reservation) in your router settings. Otherwise the printer's address can change after a power outage or router restart, and Mintcom will stop finding it until you re-enter the new IP.

5. Connecting a Bluetooth Printer

Good for single-tablet counters, mobile setups, and food trucks.

5.1 Pair the printer at the device level first

Classic Bluetooth thermal printers must be paired in your tablet's Bluetooth settings before Mintcom can see them — the app lists already-paired printers plus any it can discover directly.

  1. Turn on the printer, then press and hold its Pair button until the Bluetooth light blinks (check your model — this varies).
  2. On the tablet: Settings › Bluetooth, select the printer from the list (e.g. "Star Micronics…").
  3. If asked for a PIN, try 0000 or 1234 — the two common defaults.

5.2 Find it in Mintcom

Once paired, open Mintcom POS and use Scan Bluetooth (Chapter 6) — the printer will appear in the results ready to connect.

6. Adding the Printer Inside Mintcom POS

Once the hardware side is ready, connect it inside the app: POS › Settings › Printer Settings.

6.1 Find and connect a printer

  1. Tap Scan Bluetooth, Scan Network, or Scan All to search for nearby/paired printers. Found printers are listed — tap Connect on the one you want.
  2. No printer found? Add it manually: under Add Network Printer by IP, enter the printer's IP address (from Chapter 4.2) and Port (leave the default 9100 unless your printer's documentation says otherwise), give it an optional name (e.g. "Kitchen Printer"), and tap Add Network Printer by IP.
  3. Tap Test next to a configured printer to print a test receipt and confirm the connection.
  4. If you have more than one printer, tap Set Default on the one that should print regular sales receipts.
  5. Rename a printer anytime by tapping its name (Edit Printer Name), or remove it with Remove Printer.

6.2 Printing options

In the same Printer Settings screen:

  • Number of copies — how many copies print per receipt (1–10). Adjust with the +/− counter.
  • Open Cash Drawer — a quick-action button to fire the drawer on demand, without a sale (Chapter 7).
Note: Mintcom does not auto-print receipts — the cashier taps Print Full Receipt on the payment success screen (or reprints later from My Orders). There is also no per-printer "kitchen vs. receipts" role switch; each printer you configure is simply available to print to when needed.

6.3 Testing without a printer

Setting up before your hardware arrives, or just want to see the flow? Under Testing Mode, tap Add Debug Printer to add a virtual printer. It lets you complete sales and preview receipts on-screen exactly like a real printer would, with no hardware required.

7. The Cash Drawer

  • Mintcom does not connect to a cash drawer directly — the drawer connects to your receipt printer (via an RJ11/RJ12 cable, typically), and the printer triggers it to open.
  • Once your printer is connected and set as default (Chapter 6), the drawer opens automatically whenever a cash sale is completed.
  • To open it manually at any time (making change, start-of-day float), use Open Cash Drawer in Printer Settings, or the equivalent action on the sales screen. This requires the Open Drawer Without Making Sale permission and is logged.

8. Barcode & QR Scanners

  • Mintcom's camera can scan QR codes directly — used mainly to scan a customer's digital loyalty card (Google Wallet / Apple Wallet pass or pass page) at the counter, via Loyalty › Scan QR Code on the sales screen.
  • A physical handheld barcode/QR scanner gun (the kind that types like a keyboard — HID mode) can also be used the same way: point and scan while the loyalty search field is focused, and the code is entered automatically.
  • These devices connect over Bluetooth or USB directly to the tablet (as a keyboard peripheral) — this is separate from receipt printer connectivity in Chapter 3, and USB is fine here since the scanner behaves as a keyboard, not a printer.
Note: product lookup (adding items to the cart) is done by tapping the item tile or searching by name — Mintcom does not currently scan a product barcode to add it to the cart.

9. Multi-Device & Multi-Register Setups

  • Connect as many tablets as you like to the same Location ID — they all share the same live menu, stock, staff, and settings, and sync in real time (User Manual, Chapter 7.7).
  • A network printer can be shared by every tablet on the same Wi-Fi; add it once on each device using the same IP address.
  • A Bluetooth printer can only be connected to one device at a time — use network printers instead if several registers need to share one printer.
  • Each staff member signs in on whichever tablet they're using; only one shift can be open per register at a time (User Manual, Chapter 8.1).

10. Troubleshooting

SymptomWhat to check
Printer not printingPaper loaded correctly (feeds from under the roll); printer cover fully closed; power light on.
Network printer not foundEthernet cable clicks in on both ends; print a fresh status sheet — if the IP shows 0.0.0.0, check the cable/switch/router; confirm the tablet is on the same network as the printer (guest Wi-Fi networks often block device-to-device traffic — avoid them for POS gear).
Printer's IP address changed overnightIt's likely on DHCP and was reassigned after a router restart. Set a static IP or DHCP reservation (Chapter 4.3), then re-add the printer with the new IP.
Bluetooth printer not appearing in Scan BluetoothPair it first in the tablet's OS Bluetooth settings (Chapter 5.1) — the app can only find printers that are already paired or actively discoverable.
"Printer Already Exists"A printer with that IP and port is already configured — check the existing list before adding it again.
Cash drawer won't openConfirm the receipt printer itself is connected and prints correctly — the drawer depends entirely on the printer connection (Chapter 7).
App running slowly or crashingUpdate the app from the App Store/Play Store; restart the tablet; confirm you have a working internet connection (Mintcom keeps working offline for sales, but stays fastest with a stable connection — User Manual, Chapter 15).
Still stuckContact support with the printer model, connection type (Network/Bluetooth), and what you see on screen — see Chapter 12.

11. Setup Checklist

  • ☐ Tablet meets the minimum OS version and is fully updated.
  • ☐ Mintcom POS installed and connected with the Location ID.
  • ☐ Device locked to Mintcom with Guided Access (iPad) or App Pinning (Android), if it's a shared counter device.
  • ☐ Printer chosen with Network or Bluetooth connectivity (not USB-only).
  • ☐ Network printer: static IP assigned; same Wi-Fi network as the tablets.
  • ☐ Bluetooth printer: paired in the tablet's Bluetooth settings first.
  • ☐ Printer added in POS › Settings › Printer Settings, test receipt printed successfully, set as default.
  • ☐ Cash drawer opens correctly on a test cash sale.
  • ☐ Copies count set to what you want per sale.
  • ☐ If used, barcode/QR scanner gun tested against a loyalty pass.
  • ☐ Repeated on every additional register/tablet in the store.
